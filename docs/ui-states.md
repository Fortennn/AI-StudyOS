# Стани інтерфейсу та повний сценарій роботи (`AI StudyOS`)

## Архітектурні рішення UI (ПР17)

1. **Технологія інтерфейсу:** статична сторінка [static/index.html](../static/index.html) (HTML + Vanilla JS + Tailwind CDN), що віддається тим самим FastAPI-сервером ([app/main.py](../app/main.py)).
   - **Причина:** мінімальна складність розгортання без окремого build-кроку та без потреби налаштовувати CORS; інтерфейс спілкується виключно через API-контракт (`/api/*`).
2. **Спосіб очікування:** синхронний `POST /api/generate` з індикатором прогресу, кнопкою «Скасувати» (`AbortController`) та заголовком `Idempotency-Key` (UUID форми). Оскільки результат є структурованим JSON (`StudyKitResponse`), який валідується 3 шарами цілком перед показом, потокове виведення сирого JSON не використовується.
3. **Редагування та підтвердження зовнішніх дій:** сценарій створює лише навчальні матеріали (самарі, картки, тести) у власній історії користувача без зовнішніх побічних дій (листів, замовлень чи змін у сторонніх системах), тому окремий етап `awaiting_confirmation` / `PATCH` не потрібен.

## Перелік станів екрана

| Стан | Що бачить користувач | Доступні дії / кнопки | Подія переходу далі | Як викликати для перевірки |
| :--- | :--- | :--- | :--- | :--- |
| **1. Порожній (`home`)** | Опис можливостей, поле теми, поле тексту з лімітом із `/api/ui-config`, кнопка `⚡ Зразок`, завантаження `PDF/DOCX/TXT`, лічильник символів `0 / 250 000` | Ввести текст, завантажити файл, натиснути `Зразок`, відкрити налаштування | Введення тексту або вибір зразка -> стан `Введення`; клік `Сформувати простір` -> перевірка | Відкрити `/` у браузері |
| **2. Введення** | Заповнені тема/текст або прикріплений файл (`назва + розмір`), активна кнопка `Сформувати простір` | Редагувати текст, змінити кількість карток/тестів, натиснути `Сформувати простір` | Натискання `Сформувати простір` (успішна перевірка меж) -> `Очікування` | Ввести ≥ 10 символів або натиснути `⚡ Зразок` |
| **3. Помилка введення (`422` / клієнт)** | Червона підказка `#textFieldError` прямо під полем введення (`aria-describedby`) та банер `#errorBox`; введений текст не зникає | Виправити поле, натиснути `Сформувати простір` знову; кнопка `Повторити` прихована (`retryable=false`) | Виправлення вводу -> `Введення` | Ввести `< 10` символів і натиснути `Сформувати простір` (або відправити `POST /api/generate` з коротким `text`) |
| **4. Очікування** | Кнопка `Сформувати простір` вимкнена (`disabled`, `aria-busy="true"`), спінер + напис `Генерація та перевірка...`, з'являється кнопка `Скасувати` | Лише `Скасувати` (`AbortController.abort()`) | Відповідь `200` -> `Готовий результат` / `Даних не вистачає`; помилка -> `Контрольована помилка` / `Мережа`; клік `Скасувати` -> `Скасовано` | Натиснути `Сформувати простір` на валідному конспекті |
| **5. Скасовано** | Банер `#errorBox` з повідомленням «Запит скасовано користувачем. Введений текст збережено.» та кнопкою `Повторити` | Змінити текст або натиснути `Повторити` | Повторне надсилання -> `Очікування` | Натиснути `Скасувати` під час виконання запиту |
| **6. Готовий результат (`viewHub`)** | Бейдж походження (`Mock-провайдер` / `Основна модель` / `Записана відповідь` / `Кеш (Idempotent)`), бейдж перевірок (`Перевірено: schema · rules · content`), картки режимів (3D картки, Квіз, Бліц, Правда/Пастка, AI-тьютор) | Перейти в будь-який режим, ставити запитання в чаті, відкрити історію | Вибір режиму або повернення через `← Інший конспект` | Згенерувати комплект на `LLM_PROVIDER=mock` або `gemini` |
| **7. Даних не вистачає (`insufficient_data`)** | Жовтий банер `#insufficientDataBanner` у хабі з текстом `summary.missing_info` та кнопкою `Доповнити текст` | Натиснути `Доповнити текст` (повертає на форму без втрати введеного) | Повернення на форму -> `Введення` | Повернути від провайдера `summary.insufficient_data = true` і непорожній `missing_info` |
| **8. Контрольована помилка** | `#errorBox` зі зрозумілою назвою (зі словника `ERROR_UI_MAP`), текстом для користувача, наступним кроком, кнопкою копіювання `request_id`; кнопка `Повторити` показується лише при `retryable=true` | Скопіювати `request_id`, натиснути `Повторити` (якщо `retryable=true`, наприклад `503`/`429` rate_limit) або змінити вхід (`budget`, `invalid_output`) | Повторна спроба -> `Очікування` | Задати `MOCK_FAILURE_KIND=unavailable` (503, `retryable=true`) або перевищити `BUDGET_DAILY_CALLS` (429 `budget`, `retryable=false`) |
| **9. Помилка мережі** | `#errorBox` з повідомленням «Втрачено з'єднання із сервером...» та кнопкою `Повторити` | Перевірити мережу, натиснути `Повторити` | Повтор -> `Очікування` | Зупинити сервер або увімкнути Offline у DevTools і натиснути `Сформувати простір` |
