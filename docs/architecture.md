# Архітектура системи «AI Study Copilot»

## 1. Контекст системи (C4 Level 1: System Context)

Система надає інтерфейс для швидкої трансформації конспектів та навчальних матеріалів у структуроване резюме, інтерактивні 3D флеш-картки та тестові запитання.

```mermaid
graph TD
    User["Студент / Користувач"] -->|HTTPS / Браузер| Client["Веб-клієнт (HTML5 + Tailwind CSS)"]
    Client -->|REST API / JSON| Server["FastAPI Сервер застосунку"]
    Server -->|Абстракція провайдера| Gateway["LLM Gateway"]
    Gateway -->|Режим Mock| Mock["MockProvider (Детерміновані дані)"]
    Gateway -.->|Режим Gemini (Production)| Gemini["Google Gemini API"]
    Server -->|Внутрішньопроцесний SQL| DB[("SQLite Database")]
```

## 2. Контейнери системи (C4 Level 2: Containers)

| Контейнер | Технологія | Протокол | Призначення |
| :--- | :--- | :--- | :--- |
| **Веб-клієнт** | HTML5, Tailwind CSS, Vanilla JS | HTTPS | Введення конспекту, відображення 3D карток, проходження квізу |
| **Сервер API** | Python 3.11, FastAPI, Pydantic | HTTP / JSON | Валідація запитів, бізнес-оркестрація, маршрутизація |
| **Сховище** | SQLite 3 | SQL / local file | Збереження згенерованих наборів, історія та метрики запитів |
| **Шлюз AI** | Python (Gateway pattern) | In-process call | Таймаути, ретраї, перемикання між mock та реальними провайдерами |
| **[Резерв RAG]** | Векторний індекс (ChromaDB) | In-process / IPC | Пошук фрагментів у великих підручниках (RAG) |

## 3. Шари сервера (Server Layers)

Сервер структуровано за 6 шарами з чіткими межами відповідальності:

1. **Контролер (`app/main.py`)**:
   - Обробляє HTTP-маршрути (`/api/health`, `/api/generate`, `/api/history`).
   - Генерує наскрізний `request_id` для кожного запиту.
   - Повертає статичний фронтенд та обробляє помилки у єдиному форматі.
2. **Прикладний сервіс (`app/service.py`)**:
   - Реалізує сценарій предметної області.
   - Координує оркестратор, шлюз та сховище даних.
   - Може викликатися напряму з тестів без підняття HTTP-сервера.
3. **Оркестрація AI (`app/orchestration.py`)**:
   - Знає текст інструкцій (системний промпт).
   - Формує запит до моделі та перевіряє відповідність JSON схемі (Structured Outputs).
4. **Шлюз AI (`app/gateway.py`)**:
   - Знає назву моделі з конфігурації.
   - Керує таймаутами, спробами повтору (retry), обробкою збоїв провайдера.
5. **Абстракція провайдера (`app/providers/`)**:
   - Єдиний контракт `LLMProvider` (`generate()`).
   - `MockProvider`: детерміновані дані, емуляція затримок та збоїв.
   - Реальний провайдер (production Gemini API).
6. **Сховище даних (`app/storage.py`)**:
   - Забезпечує збереження запитів та результатів у SQLite.
   - Підтримує швидку заміну на `:memory:` для юніт-тестів.
