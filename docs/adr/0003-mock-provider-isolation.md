# ADR 0003: Ізоляція AI-провайдера через MockProvider на етапі прототипу

## Статус
Прийнято

## Контекст
Каркас системи (walking skeleton) має повноцінно функціонувати та проходити тести без реального виклику платного AI API і без наявності секретного ключа.

## Рішення
Впроваджено абстрактний клас `LLMProvider` та повноцінну реалізацію `MockProvider`. Mock-провайдер:
1. Повертає детерміновані структуровані JSON-відповіді відповідно до схеми `StudyKitResponse`.
2. Емулює затримку мережі (`MOCK_DELAY_MS`).
3. Може відтворювати збої (`MOCK_FAILURE_KIND`: таймаут, 429, недоступність) для перевірки реакції інтерфейсу та шлюзу.

## Наслідки
* **Плюси:** Система клонується й запускається однією командою; тести в CI/CD або на локальній машині проходять безкоштовно та гарантовано; усунуто ризик випадкового списання коштів за невдалий тест.
* **Перемикання:** Заміна на реальну модель Gemini виконується зміною єдиної змінної середовища `LLM_PROVIDER=gemini`.
