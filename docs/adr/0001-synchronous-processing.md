# ADR 0001: Синхронна обробка запитів генерації конспекту

## Статус
Прийнято

## Контекст
Користувач надсилає фрагмент лекції чи конспекту обсягом до 15 000 символів для отримання резюме, карток та тесту. Необхідно вирішити: обробляти запит синхронно (блокуючий HTTP 200) чи асинхронно через фонову чергу (HTTP 202 Accepted + SSE або polling).

## Рішення
Для базової версії (MVP) реалізувати **синхронну обробку (HTTP 200)**. Flash-моделі сучасних провайдерів (Google Gemini 2.5 Flash або MockProvider) відповідають за 0.8–2.0 секунди, що є комфортним часом очікування для інтерфейсу.

## Наслідки
* **Плюси:** Відсутність потреби у важкій інфраструктурі (Celery, Redis, веб-сокети), простий API-контракт, мінімальна кількість коду.
* **Мінуси:** Якщо користувач передасть надвеликий текст (100+ сторінок книги), браузер може отримати таймаут.
* **Подальший розвиток:** У наступних релізах при інтеграції великих PDF передбачено перехід на фонову обробку через таски FastAPI.
