# ADR 0002: Використання SQLite як вбудованого сховища

## Статус
Прийнято

## Контекст
Застосунку необхідно зберігати історію згенерованих навчальних комплектів, логи запитів та результати проходження тестування користувачем.

## Рішення
Обрано вбудовану базу даних **SQLite 3** (`data/study.db`), доступ до якої інкапсульовано у модулі `app/storage.py`.

## Наслідки
* **Плюси:** Не вимагає встановлення та адміністрування окремого сервера СУБД (PostgreSQL/MySQL), зберігається у файлі в проєкті, запускається «з коробки».
* **Тестування:** Модуль сховища дозволяє миттєво підмінити шлях на `:memory:` під час прогону тестів, забезпечуючи ізоляцію та швидкість за 10 мс.
* **Обмеження:** Не підходить для розподіленого горизонтального масштабування з багатьма паралельними екземплярами бекенду (що не вимагається для навчального прототипу).
